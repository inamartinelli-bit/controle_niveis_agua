# 🚰 CONTROLE DE NÍVEIS DE ÁGUA 🚱

## 🎯 Objetivo do sistema

🏹  Auxiliar no desenvolvimento de um sistema simples de monitoramento de um reservatório de água;

🏹  Exibir mensagens de alerta com cores diferentes, conforme o nível de água no reservatório.

## 💻 Sintaxe do código

    👩‍💻 A estrutura de dados **Listas** armazena cinco níveis de água do reservatório acessando cada um deles.

    👩‍💻 A **mBiblioteca Colorama** é importada para evidenciar as mensagens referentes aos níveis de água do reservatório através das cores

    👩‍💻 O bloco de códigos estruturado pela **Função verificar_nivel**, verifica o nível do  reservatório, recebendo o nível como parâmetro

    👩‍💻 As estruturas de decisão **if/elif/else** executam os blocos de códigos para verificação dos níveis de áugas do reservatório. O programa exibi cinco situações do reservatório.

---

## ⚙️ Instruções da execução do programa

    🔧 O programa executa uma simulação de um ambiente real de monitoramento;

    🗜️ O programa não solicita ao usuário a inserção dos dados;

    🪛 A simulação é feita com valores definidos no código;

    🔨 O programa finaliza restaurando o estilo padrão do terminal após a exibição das mensagens.
